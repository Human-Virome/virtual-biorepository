Data Saved to Repository

The data from your uploaded template has been successfully processed and securely stored in the repository.

You may now want to navigate to the Browse tab. From there, you can:

  • View your imported records.
  • Set permissions to allow others to view or contribute to this dataset.
  • Make further edits if needed.
  • Finalize the data to generate NCBI BioSample IDs and enable the data to be exported for SRA submission.
